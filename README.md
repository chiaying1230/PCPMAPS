# PCP MAPS 互動地圖

以人為中心計畫（Person-Centred Planning）MAPS 訪談整理的空白範本。地圖畫成一座機場，並且照顧視障者的閱讀需求。

**線上使用：** https://chiaying1230.github.io/PCPMAPS/

## 功能

- **機場主題地圖**：故事是護照，夢想是飛機，惡夢是烏雲和鴿子，天賦與貢獻是行李箱，需要什麼是跑道，行動約定是航班看板，回應與承諾是塔台。
- **點地圖放大成全螢幕**，再點區塊可以放大成一頁一頁的簡報，用左右方向鍵切換，按 Esc 回到地圖。
- **文字版**：內容排成一欄，適合螢幕報讀軟體（NVDA、JAWS、VoiceOver）用標題鍵逐區閱讀。
- **閱讀設定**：字級可以放大到 200%，也可以切換成黑底黃字的高對比模式。
- **編輯模式**：直接在網頁上填寫訪談內容，按「儲存成新檔案」會下載一份 HTML 檔到你的電腦。

## 怎麼填寫自己的訪談

1. 打開上面的網址，按「編輯內容」→「編輯模式」。
2. 在「文字版」和「訪談資訊」裡填寫內容。
3. 按「儲存成新檔案」，之後打開下載的 HTML 檔繼續編輯。

## 隱私提醒

這個網站是公開的，所以這裡只放空白範本。**請不要把填了真實訪談內容的檔案上傳到這個 repository。**

用編輯模式填寫的內容只會下載到你自己的電腦，不會上傳到 GitHub。
